UV adaptatifs à la résolution

Chaque modèle possède une taille UV native (par exemple 64×64, 64×32 ou 128×64). Le viewer utilise ces coordonnées en valeurs normalisées : si tu charges une texture 1024×1024 pour un modèle 64×64, le même mapping est utilisé à l’échelle 16×. Une alerte apparaît si le ratio de ton image ne correspond pas au modèle.

Sources du catalogue : modèles CEM Java Edition utilisés par le plugin Blockbench CEM Template Loader.
