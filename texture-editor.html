MÉTHODE B · GUIDÉE

Guide UV avec noms de parties

Recommandé pour les modèles répétitifs

Cette méthode ajoute une étape : ChatGPT reçoit le skin Minecraft de base et produit une copie annotée du même atlas. Chaque face doit porter un nom machine-readable comme HEAD_FRONT, BODY_LEFT, LEG_1_FRONT ou WING_RIGHT_PLANE_2.

Les parties identiques ou répétées doivent obligatoirement avoir des noms uniques avec un numéro. Le guide annoté sert uniquement à expliquer « quoi est quoi » ; le template original reste la référence géométrique.
