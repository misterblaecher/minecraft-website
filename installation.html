🧰 Tutoriel d'installation complet

Minecraft 1.21.1 • NeoForge 21.1.251 • Packs Lite / Standard / Ultra

1

Installer Java 21 (64 bits)

Minecraft 1.21.1 avec NeoForge nécessite Java 21. Installe une version 64 bits si Java 21 n'est pas déjà présent.

☕ Télécharger Java 21 Documentation NeoForge

Pour vérifier, ouvre PowerShell ou l'invite de commandes et exécute :

java -version

La première ligne doit indiquer une version 21 et une JVM 64 bits.

2

Installer NeoForge 21.1.251

Ferme complètement le Minecraft Launcher avant de lancer l'installateur.

⬇️ Télécharger NeoForge 21.1.251
  1. Télécharge neoforge-21.1.251-installer.jar.
  2. Double-clique sur le fichier.
  3. Choisis Install client.
  4. Clique sur Proceed et attends le message de réussite.
  5. Rouvre le Minecraft Launcher : un profil NeoForge doit être disponible.
Si le double-clic ne lance rien : ouvre un terminal dans le dossier du fichier et exécute : 
java -jar neoforge-21.1.251-installer.jar
3

Lancer NeoForge une première fois

  1. Dans le Launcher, ouvre Installations et crée de préférence une installation séparée pour le serveur.
  2. Sélectionne la version NeoForge 21.1.251 / Minecraft 1.21.1.
  3. Choisis un dossier de jeu dédié, par exemple C:\Minecraft\GabCon-1.21.1, afin de ne pas mélanger ce pack avec tes autres mods.
  4. Lance cette installation une fois jusqu'au menu principal, puis ferme Minecraft.

Après le premier lancement, le dossier mods apparaît dans le répertoire de jeu. Si shaderpacks ou resourcepacks n'existent pas encore, tu peux simplement les créer.

Si tu choisis malgré tout le dossier Minecraft par défaut sous Windows, il se trouve généralement dans %appdata%\.minecraft.

5

Installer les mods

  1. Décompresse le ZIP téléchargé.
  2. Ouvre le dossier extrait ModPack Lite, ModPack Standard ou ModPack ULTRA.
  3. Sélectionne tous les fichiers .jar qui se trouvent dedans.
  4. Copie-les dans le dossier mods de ton instance NeoForge.
Le résultat doit ressembler à : ton-dossier-jeu\mods\create-1.21.1-6.0.10.jar, ton-dossier-jeu\mods\ftb-library-....jar, etc.
Important : ne copie pas le dossier ModPack Standard lui-même dans mods. Les fichiers .jar doivent être directement dans mods. Supprime aussi les anciens mods d'une ancienne version avant d'installer ce pack.
6

Ultra : installer le shaderpack

Cette étape est uniquement utile pour le pack Ultra. Iris est déjà inclus dans Ultra, mais le shaderpack se télécharge séparément.

⬇️ Complementary Unbound
  1. Ne décompresse pas le fichier shader .zip.
  2. Place-le dans shaderpacks à l'intérieur de ton dossier de jeu.
  3. Lance Minecraft.
  4. Va dans Options → Vidéo → Shader Packs et sélectionne Complementary Unbound.

Si les FPS baissent trop, désactive les shaders ou utilise le pack Standard.

7

Installer le Resource Pack Gab Con

⬇️ Télécharger Gab Con
  1. Garde le fichier au format .zip.
  2. Place-le dans resourcepacks à l'intérieur de ton dossier de jeu.
  3. Dans Minecraft : Options → Packs de ressources.
  4. Active Gab Con.
8

RAM conseillée

  • Lite : 3–4 Go alloués à Minecraft.
  • Standard : 4–6 Go.
  • Ultra : 6–8 Go.

Dans le Launcher officiel : Installations → ton profil NeoForge → Plus d'options, puis adapte la valeur -Xmx dans les arguments JVM.

Exemple pour 6 Go :

-Xmx6G

N'alloue pas toute la RAM du PC à Minecraft : Windows, le launcher et les autres applications en ont aussi besoin.

9

Lancer et rejoindre le serveur

  1. Démarre toujours Minecraft avec le profil NeoForge 1.21.1.
  2. Vérifie que le menu Mods affiche bien les mods du pack.
  3. Va dans Multijoueur et utilise l'adresse du serveur communiquée sur le site ou le Discord.
Installation terminée. Lite, Standard et Ultra gardent le même gameplay serveur ; seules les options graphiques/performance changent.

🛠️ Problèmes fréquents

  • Le fichier NeoForge ne s'ouvre pas : vérifie Java 21 et utilise la commande java -jar ....
  • Le jeu démarre sans mods : vérifie que tu utilises bien le profil NeoForge et le bon dossier mods.
  • Erreur de mods incompatibles : vide les anciens .jar avant de copier le nouveau pack.
  • Ultra plante avec les shaders : désactive le shaderpack et teste d'abord sans shaders ; Iris utilisé dans Ultra est une version bêta.
  • FPS faibles : passe de Ultra à Standard ou Lite.
