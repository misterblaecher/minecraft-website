Installer Java 21

NeoForge 1.21.1 a besoin de Java 21 en 64 bits.

☕ Télécharger Java 21
  1. Télécharge Java 21 pour Windows 64 bits puis lance l'installateur.
  2. Laisse les options par défaut et termine l'installation.
  3. Ouvre PowerShell et tape java -version.

C'est bon si : la première ligne affiche une version qui commence par 21.

Ferme complètement le Minecraft Launcher avant de lancer l'installateur.

⬇️ Télécharger NeoForge
  1. Ouvre neoforge-21.1.251-installer.jar.
  2. Coche Install client.
  3. Clique sur Proceed.

3

Créer une installation GabCon séparée

C'est la façon la plus simple d'éviter de mélanger GabCon avec d'autres mods.

  1. Launcher → Installations → Nouvelle installation.
  2. Choisis NeoForge 21.1.251.
  3. Définis par exemple C:\Minecraft\GabCon-1.21.1.
  4. Lance le jeu une fois jusqu'au menu principal, puis ferme-le.
C:\Minecraft\GabCon-1.21.1\ ├─ mods\ ← les fichiers .jar iront ici ├─ shaderpacks\ ← shader Ultra ├─ resourcepacks\ ← pack Gab Con ├─ config\ └─ logs\
C'est bon si : le dossier mods existe après le premier lancement.

Télécharger Lite

🔵 Standard · 26 JAR

La majorité des PC. Iris + Distant Horizons + GabCon DH Sync.

Télécharger Standard

Mêmes mods que Standard, avec shader et réglages plus élevés.

Télécharger Ultra

Mettre les mods au bon endroit

C'est l'étape la plus importante : les fichiers .jar doivent être directement dans mods.

  1. Décompresse le ZIP du pack dans un dossier temporaire.
  2. Ouvre le dossier extrait et sélectionne tous les fichiers .jar.
  3. Copie-les dans C:\Minecraft\GabCon-1.21.1\mods\.

📁GabCon\mods\coller ici
À ne pas faire : ne mets pas le ZIP dans mods et ne mets pas non plus un dossier contenant les JAR. Les JAR doivent être directement visibles dans mods.
Exemple correct : ...\mods\create-1.21.1-6.0.10.jar.
6

Standard / Ultra : enregistrer GabCon DH Sync

Cette étape concerne uniquement Standard et Ultra. Le nouveau Lite n'inclut pas Distant Horizons ni GabCon DH Sync.

Tu utilises Lite ? Passe directement à l'étape 7.
  1. Lance Minecraft avec Standard ou Ultra et rejoins GabCon.
  2. Attends que le monde soit complètement chargé.
  3. Dans le chat, tape /gabcondhsyncclient register.
  4. Quitte le serveur puis reconnecte-toi.

8

Checklist avant de jouer

Si tout ce qui suit est vrai, ton installation est prête.

  • Le launcher démarre NeoForge 1.21.1.
  • Le menu Mods affiche les mods du pack.
  • Aucun ancien JAR n'est mélangé.
  • Lite n'a ni Iris ni Distant Horizons.
  • Standard / Ultra ont DH 3.3.2 + GabCon 0.6.2.
  • Ultra peut activer le shader si le PC le supporte.

Problèmes fréquents

Ouvre seulement le cas qui correspond à ton problème.

Le fichier NeoForge ne s'ouvre pas

Vérifie java -version. Si Java 21 est installé, ouvre un terminal dans le dossier de l'installateur et lance java -jar neoforge-21.1.251-installer.jar.

Minecraft démarre mais aucun mod n'apparaît

Tu as probablement lancé Vanilla ou copié les JAR dans le mauvais dossier. Vérifie le dossier de jeu de ton installation NeoForge.

Erreur de mod en double ou incompatible

Ferme Minecraft, retire les anciens JAR du dossier mods, puis recopie uniquement les fichiers du pack actuel.

Les shaders font chuter les FPS

Désactive le shaderpack ou passe de Ultra à Standard. Le shader est facultatif.
